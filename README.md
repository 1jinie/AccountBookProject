# Simple한 가계부
콘솔 환경에서 동작하는 java기반의 가계부 프로그램입니다.  
사용자는 수입/지출을 기록하고, 월별 내역과 잔액을 확인할 수 있습니다.  
입출력/자료구조/객체지향 설계를 연습합니다.

## Tech stack
- Java 21 (Zulu 21.0.11)
- File I/O (CSV Reader/Writer)
- Collection Framework (ArrayList)
- Design Patterns (Singleton, Strategy/Command via Controller interface)

## 필드 (AccountVO)
- `int id` : 고유 식별자 (자동 증가)
- `String type` : 수입 / 지출 구분
- `int amount` : 금액
- `String description` : 내용
- `String category` : 분류 (식비, 교통, 월급 등)
- `Calendar date` : 입력 날짜

## 주요 기능
- **수입/지출 입력**: 내역을 입력받아 메모리에 저장 및 ID 자동 할당
- **전체 내역 조회**: 저장된 모든 가계부 내역 출력
- **월별 내역 조회**: 특정 월(1-12)을 입력받아 해당 월의 내역만 필터링
- **잔액 계산**: 수입(+)과 지출(-)을 합산하여 현재 잔고 확인
- **데이터 지속성**: 프로그램 종료 시 `account.csv`로 자동 저장, 실행 시 자동 로드

## 실행 방법
1. Java 21 환경에서 `src/main/java/main/AccountMain.java` 파일을 실행합니다.
2. 콘솔에 출력되는 메뉴 번호를 입력하여 기능을 수행합니다.

## 사용 예시
```
----- 가계부 프로그램을 실행합니다 -----
1. 수입 입력
2. 지출 입력
3. 전체 내역 조회
4. 월별 내역 조회
5. 잔액 확인
0. 종료

실행할 번호를 입력하세요 : 1
--- 수입 내역을 입력합니다 ---
금액 : 2500000
내용 : 월급
카테고리 : 급여
날짜 (yyyy-MM-dd, 미입력 시 오늘 날짜) : 2026-06-01
수입 내역이 추가되었습니다.
```

## 프로젝트 구조
- `main`: 프로그램의 진입점(Entry Point)인 `AccountMain` 클래스가 위치하며, 메인 루프를 관리합니다.
- `controller`: 사용자 요청을 처리하는 컨트롤러 클래스들입니다. `Controller` 인터페이스를 기반으로 각 기능이 분리되어 있으며, `HandlerMapping`이 번호에 맞는 컨트롤러를 반환합니다.
- `service`: 비즈니스 로직 및 데이터 관리를 담당하는 `AccountService`가 위치합니다. 싱글톤 패턴으로 구현되어 데이터의 일관성을 유지하며 CSV 파일 입출력을 처리합니다.
- `vo`: 가계부 데이터를 담는 객체인 `AccountVO`가 위치합니다.

## 설계 의도
- **MVC 패턴 지향**: 데이터(VO), 로직(Service), 제어(Controller)를 분리하여 유지보수성을 높였습니다.
- **인터페이스 활용**: 각 기능을 `Controller` 인터페이스로 추상화하여, 새로운 기능 추가 시 `HandlerMapping`에 등록만 하면 되도록 확장성을 고려했습니다.
- **싱글톤 패턴**: 데이터 저장소와 핸들러 매핑을 싱글톤으로 관리하여 메모리 낭비를 줄이고 전역에서 동일한 데이터에 접근하게 설계했습니다.
- **예외 처리**: 사용자 입력 오류나 파일 I/O 오류 시 프로그램이 비정상 종료되지 않도록 예외 처리 로직을 포함했습니다.
